Guía Didáctica y Publicación en GitHub Pages

1. Formato de datos en MakeCode (micro:bit)

Para que este Dashboard lea tus datos por puerto Serie, asegúrate de que tu micro:bit envíe la palabra clave Pulso mediante el bloque de serie: 

serial.writeValue("Pulso", pins.analogReadPin(AnalogPin.P0))

2. ¿Cómo subir este Dashboard a GitHub Pages?

  1. Crea un nuevo repositorio en GitHub llamado mi-cardiobit.
  2. Sube este archivo guardándolo con el nombre exacto index.html.
  3. Ve a Settings > Pages en tu repositorio.
  4. En Branch, selecciona main y guarda. ¡Tu web estará online en minutos!
